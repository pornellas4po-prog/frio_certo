## Story

**Como** dono do sistema,
**quero** o projeto organizado (frontend Next.js, backend e worker Python no mesmo repositório),
**para** começar o desenvolvimento com padrão definido.

## Acceptance Criteria

1. Frontend, backend e worker sobem localmente com um comando documentado no README.
2. Variáveis de ambiente documentadas em `.env.example`, sem segredos no repositório.

## Escopo

**Dentro:**
- `backend/` e `worker/` com `pyproject.toml` (Python 3.13, uv) e `GET /health`
- `package.json` na raiz com `npm run dev` (concurrently) subindo os três serviços
- Dockerfiles dos três serviços; `output: 'standalone'` no Next.js
- ESLint (com `eslint-plugin-jsx-a11y`) e Vitest no frontend
- `.env.example` completo (arquitetura §10) e `.github/workflows/ci.yml` (§12)

**Fora:**
- Banco de dados e Supabase (Story 1.3)
- Login (Story 1.4)
- Publicação no Easypanel (Story 1.6)
